# TRADERS — Твой первый миллион

Современный, адаптивный лендинг для привлечения партнеров в трейдинговую платформу. Создан с использованием **React**, **TypeScript** и **Vite** для максимальной производительности и плавного UX.

![React](https://img.shields.io/badge/React-19.x-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue) ![Vite](https://img.shields.io/badge/Vite-5.x-purple)

##  Особенности проекта

*   **Анимированная статистика** — счетчики выведенных средств и активных трейдеров
*   **Эффект печатающегося текста** — динамический заголовок
*   **Particle system** — интерактивный фон с частицами
*   **Cursor trail** — эффект шлейфа за курсором
*   **Confetti эффект** — праздничная анимация при клике на CTA
*   **Toast уведомления** — имитация активности пользователей в реальном времени
*   **Konami Code** — пасхалка (↑↑↓↓←→←→B A)
*   **Scroll reveal** — плавное появление элементов при скролле
*   **Адаптивный дизайн** — мобильное меню с гамбургером
*   **Параллакс эффекты** — глубина и объем на всех секциях

## 🚀 Технологии

*   **React 19.3.1** — UI библиотека с хуками
*   **TypeScript 5.x** — типизация и надежность кода
*   **Vite 5.x** — Быстрый сборщик и dev-сервер
*   **CSS3** — Современная стилизация (Grid, Flexbox, Backdrop-filter, Animations)
*   **JavaScript ES6+** — Модульная архитектура и асинхронность
